# Memory Layer — 3-Tier Persistent Memory

Thư mục `memory/` đóng vai trò là **Tier 3 (Episodic Memory)** trong kiến trúc bộ nhớ 3 phân tầng của Harness Engineering:

- `scratchpad.md`: Bộ nhớ đệm ngắn hạn cho tác vụ đang chạy giữa các bước phân tích/tự sửa.
- `working-context.md`: Snapshot trạng thái của tính năng hiện tại, vai trò phụ trách và tài liệu liên đới.
- `project-state.md`: Tiến độ tổng thể của các Value Streams và các milestone tiếp theo.
- `role-handoff-state.md`: Nhật ký bàn giao artifact vật lý giữa các vai trò.
- `agent-trace-log.md`: Dấu vết lịch sử thực thi của Agent.
