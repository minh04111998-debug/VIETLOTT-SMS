# Critique Conflicts Archive

Thư mục này lưu trữ các biên bản ghi nhận bất đồng (Deadlock Escalation Dossiers) khi quy trình CRITIQUE giữa các Agent thất bại quá 2 lần liên tiếp.

## Cấu Trúc Biên Bản Bất Đồng:
Mỗi file sẽ được đặt tên theo định dạng: `CC-[YYYYMMDD]-[Feature-Name].md` và bao gồm:
1. **Bối cảnh & Artifact đang xét duyệt:** Đường dẫn file, phiên bản.
2. **Quan điểm của Agent đề xuất (e.g. BA/DEV):** Luận điểm và bằng chứng.
3. **Quan điểm của Agent phản biện (e.g. QA/Governance):** Lý do từ chối và rủi ro cảnh báo.
4. **Các phương án đánh đổi (Trade-offs):** Phương án A vs Phương án B.
5. **Đề xuất xin ý kiến Human phân xử:** Quyết định cần Human chốt.
