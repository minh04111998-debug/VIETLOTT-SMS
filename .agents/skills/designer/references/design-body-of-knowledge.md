## Nielsen Norman Group — 10 Usability Heuristics

| # | Heuristic | Tóm Tắt |
|---|-----------|----------|
| 1 | Visibility of System Status | Luôn cho user biết đang xảy ra gì |
| 2 | Match Between System and Real World | Dùng ngôn ngữ user hiểu |
| 3 | User Control and Freedom | Undo, redo, exit rõ ràng |
| 4 | Consistency and Standards | Follow platform conventions |
| 5 | Error Prevention | Design để prevent lỗi trước khi xảy ra |
| 6 | Recognition Rather Than Recall | Hiển thị options, giảm memory load |
| 7 | Flexibility and Efficiency of Use | Shortcuts cho expert users |
| 8 | Aesthetic and Minimalist Design | Chỉ hiện info cần thiết |
| 9 | Help Users Recognize and Recover from Errors | Error messages rõ ràng + recovery |
| 10 | Help and Documentation | Easy to search, task-focused |

> Nguồn: [NNG 10 Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)

## Laws of UX (Jon Yablonski)

| Law | Tóm Tắt | Áp Dụng |
|-----|---------|----------|
| Fitts's Law | Target size ∝ importance | CTA buttons lớn, close to cursor |
| Hick's Law | Choices ↑ → Decision time ↑ | Limit options, progressive disclosure |
| Miller's Law | 7±2 items in working memory | Chunk information, limit nav items |
| Jakob's Law | Users prefer familiar patterns | Follow conventions, don't reinvent |
| Aesthetic-Usability | Beautiful = perceived easier | Invest in visual polish |
| Doherty Threshold | Response < 400ms feels instant | Optimize perceived performance |
| Law of Proximity | Close items = related | Group related controls |
| Law of Common Region | Shared boundary = group | Use cards, sections, borders |
| Peak-End Rule | Judge experience by peak + end | Nail key moments + checkout |
| Von Restorff Effect | Different item stands out | Highlight primary actions |

> Nguồn: [lawsofux.com](https://lawsofux.com/)

## WCAG 2.2 — POUR Principles

| Principle | Meaning | Key Success Criteria |
|-----------|---------|---------------------|
| **P**erceivable | Content available to senses | Text alternatives, captions, contrast |
| **O**perable | Interface can be operated | Keyboard access, no seizures, enough time |
| **U**nderstandable | Content readable & predictable | Clear language, consistent nav, input help |
| **R**obust | Works with assistive tech | Valid HTML, ARIA, name/role/value |

> Nguồn: [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | [Quick Ref](https://www.w3.org/WAI/WCAG22/quickref/)
