# Kỹ Năng: QA Testing (Core Index)

## Mô Tả
Skill gốc cho vai trò Quality Assurance. File này là **dispatch table**.

## Skill Dispatch Table

| Khi task liên quan đến... | Nạp skill | Mô tả |
|--------------------------|-----------|-------|
| Test strategy, test plan, test cases, test data, performance test plan | `qa-test-plan` | Lập kế hoạch & thiết kế test |
| Playwright setup, code gen, browser testing, API testing, automation | `qa-automation` | Test automation & execution |
| Bug report, triage, regression, security checklist, test monitoring | `qa-bug-management` | Bug management & quality gate |
| Thẩm định chất lượng output Test Plan, Test Matrix, Bug Report theo chuẩn Senior ISTQB | `qa-review` | Thẩm định & kiểm thử tĩnh (Static Testing) |
