## Key Concepts Per Domain

### D1: Apply Foundational Concepts (10%)
- Product-centric vs Project-centric models
- PO role evolution: Scrum PO → POA practitioner
- Product lifecycle stages (Introduction → Growth → Maturity → Decline)
- Organizational readiness for POA
- Lean Startup principles (Build-Measure-Learn)
- Product vs Project mindset differences

### D2: Cultivate Customer Intimacy (15%)
- **Empathy Maps** — 4 quadrants + Pains/Gains
- **Value Proposition Canvas** — Customer Profile ↔ Value Map
- **Product-Market Fit** — Sean Ellis 40% test
- **Human-Centred Design** — 5 phases
- Customer Journey Mapping (3 types: Goal, Pain, Moment of Truth)
- Customer Development interviews (JTBD questions)
- Personas vs Empathy Maps (different purposes)
- Focus Groups vs 1-1 Interviews (when to use each)

### D3: Engage the Whole Team (15%)
- Stakeholder Management (Power × Interest matrix)
- **Cross-functional Collaboration** — Dual-Track, Three Amigos, Product Trio
- **Collaborative Games** — Buy a Feature, Speedboat, Product Box
- Shared PO Responsibilities — Chief PO model
- Conflict resolution protocol
- Team empowerment vs micromanagement

### D4: Make an Impact (15%)
- Product Vision & Strategy (Vision Board, NOW/NEXT/LATER Roadmap)
- OKR framework (Objective + Key Results)
- North Star Metric
- **AARRR** (Pirate Metrics) — Acquisition → Revenue
- **HEART** Framework — Google's UX quality metrics
- **Impact Mapping** — WHY → WHO → HOW → WHAT
- **Business Cases** — ROI justification per feature
- **Decision Modelling** — Decision Matrix, 6 Thinking Hats

### D5: Deliver Often (15%)
- Backlog Management — Epic → Feature → Story → Task
- INVEST criteria for User Stories
- **Story Mapping** — Jeff Patton (backbone, walking skeleton, release slices)
- **Job Stories** — "When [situation], I want [motivation], so I can [outcome]"
- **Definition Concepts** — DoR, DoV (NEW!), DoD
- Release types: Big Bang, Incremental, Feature Toggle, Canary
- Story Splitting (SPIDR)
- Conceptualizing: Sketch → Wireframe → Mockup → Prototype

### D6: Learn Fast (15%)
- Experiment & MVP — 7 types (Fake Door → Tracer Bullet)
- Hypothesis framework (Assumption → Hypothesis → MCS)
- **Opportunity Solution Tree** — Teresa Torres
- **Real Options** — 3 principles (value, expiry, don't commit early)
- **Spikes** — Technical vs Functional, timebox rules
- **Learning Loops** — Daily, Sprint, Release
- Build-Measure-Learn cycle
- Persist/Pivot/Kill decision framework

### D7: Obsess About Value (15%)
- **RICE** Score — formula & usage
- **WSJF** — Cost of Delay / Duration
- **Kano Model** — 5 categories
- **Value Stream Mapping** — current state, waste identification, future state
- **Value Modelling** — 3 dimensions (Customer, Business, Time)
- Continuous Value Optimization — measure, analyze, hypothesize, test, scale/kill
- Output vs Outcome distinction
- Saying NO with data

## Common Exam Scenario Patterns

### Pattern 1: "PO receives feature request from CEO"
- **Wrong:** Accept immediately, add to sprint
- **Right:** Evaluate with RICE/data → propose experiment/Fake Door → decide with evidence
- **Domain tested:** D7 (Obsess About Value) + D3 (Engage Team)

### Pattern 2: "Team building feature but unsure about user need"
- **Wrong:** Continue building, hope for the best
- **Right:** Pause → run customer interviews → create Empathy Map → validate with VPC
- **Domain tested:** D2 (Customer Intimacy) + D6 (Learn Fast)

### Pattern 3: "Multiple stakeholders disagree on priority"
- **Wrong:** Let loudest voice win (HiPPO)
- **Right:** Facilitate Buy a Feature game → use RICE scoring → document decision
- **Domain tested:** D3 (Engage Team) + D7 (Value)

### Pattern 4: "First release of new product"
- **Wrong:** Wait until all features ready (big bang)
- **Right:** Create Story Map → identify walking skeleton → release thin slice → learn
- **Domain tested:** D5 (Deliver Often) + D6 (Learn Fast)

### Pattern 5: "Feature shipped but nobody uses it"
- **Wrong:** Build more features on top
- **Right:** Analyze usage data → interview non-adopters → decide keep/enhance/sunset
- **Domain tested:** D7 (Value) + D2 (Customer Intimacy)
