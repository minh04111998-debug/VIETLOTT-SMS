## D6: Learn Fast (15%)

### Experiment & MVP Thinking
**Framework:** Assumption → Hypothesis → MCS (Minimum Criteria for Success)
**7 loại MVP:** Fake Door | Email/Manual | Concierge | Wizard of Oz | Shadow | Prototype | Tracer Bullet
**Kết quả:** MCS ĐẠT → Persevere | GẦN ĐẠT → Iterate | KHÔNG ĐẠT → Pivot/Kill

### Opportunity Solution Tree (Teresa Torres)
**4 tầng:** Outcome → Opportunity → Solution → Experiment
**Quy tắc:** ≥2 opportunities per outcome, ≥2 solutions per opportunity
→ Nguồn: [Continuous Discovery Habits — Teresa Torres](https://www.producttalk.org/2021/08/product-discovery/)

### Real Options
**3 Nguyên tắc:**
1. Options have value — Càng nhiều options = càng ít rủi ro
2. Options expire — Không giữ mãi, phải commit đúng lúc
3. Never commit early unless you know why — Data drives timing

### Spikes (Research Timeboxed)
**2 loại:** Technical Spike (feasibility) | Functional Spike (usability/value)
**Quy tắc:** Timebox 1-2 days | Output = recommendation + evidence | Không phải production code

### Learning Loops
**3 Loops:**
1. **Daily:** Standup insights → adjust today's focus
2. **Sprint:** Retro learnings → adjust next sprint approach
3. **Release:** Post-release data → adjust product strategy
**Template:** "We assumed [X]. We tested by [Y]. We learned [Z]. Next action: [W]."

## D7: Obsess About Value (15%)

### Prioritization Frameworks
- **RICE:** (Reach × Impact × Confidence) / Effort — dùng hàng ngày
- **WSJF:** Cost of Delay / Job Duration — cho SAFe/PI Planning
- **Kano Model:** Basic | Performance | Delight | Indifferent | Reverse
**Nói NO đúng cách:** Data + alternative, không dùng opinion

### Value Stream Mapping
**Process:**
1. Define start/end points of value stream
2. Map all steps (value-add vs non-value-add)
3. Measure lead time, process time, wait time per step
4. Identify waste (waiting, handoffs, rework, over-processing)
5. Design future state map

### Value Modelling
**Dimensions:**
- **Customer Value:** Problem severity × frequency × willingness to pay
- **Business Value:** Revenue impact + cost reduction + strategic alignment
- **Time Value:** Cost of delay, first-mover advantage

### Continuous Value Optimization
**Cycle:** Measure → Analyze → Hypothesize → Test → Scale/Kill
**Key activities:**
- Feature usage analytics review (weekly)
- Underperforming features audit (monthly)
- Value realization tracking vs business case (quarterly)
- Portfolio value assessment (semi-annual)
