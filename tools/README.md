# Tools & Integrations — Vietlott SMS

Thư mục này quản lý các công cụ kết nối ngoại vi và giao thức mở rộng:
- `jira/`: Tích hợp Jira REST API để tự động sinh issue/story từ SRS.
- `telegram/`: Tích hợp Telegram bot gửi thông báo một chiều (escalation, hoàn tất tác vụ). Không có luồng phê duyệt (DEC-008).
- `confluence/`: Tích hợp Confluence Cloud để đồng bộ tài liệu baseline.
- `tool-registry.md`: Bản đồ tra cứu toàn bộ script, tham số, phân quyền và danh sách MCP servers.
